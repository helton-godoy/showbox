# Segurança

Não abra issues públicas contendo credenciais ou dados privados. Para falhas
sensíveis, use o canal privado de segurança do repositório quando habilitado.

Projetos podem conter código Bash: abrir/editar não deve executar ações.
Execução é explícita. Não usar eval para interpretar valores de widgets.
A política detalhada existente está em docs/security.md.

Publicação e assinatura ficam restritas ao pipeline de release autorizado.
Dependências e ferramentas baixadas precisam de versão e integridade verificadas.
