# Showbox Studio

Editor visual importado da branch develop do showbox-studio. Use o CMake e o
justfile da raiz. O Studio utiliza `showbox-ui` do próprio monorepo.

Estado: experimental. O fluxo de ações/exportação da SB-002 tem teste contra o motor real para
um subconjunto de componentes. Consulte docs/user/shell-actions.md na raiz
para o escopo suportado e as limitações.
A documentação histórica em `docs/` deste módulo não é a especificação vigente.
